* Arraylist -> Dynamic array (growing array)  // import java.util.Arrays

* SYNTAX:

        ArrayList<data_type> variable_name = new ArrayList<>();

* E.g:

        ArrayList<Integer> arr1 = new ArrayList<>();
        ArrayList<Character> arr2 = new ArrayList<>();
        ArrayList<String> arr3 = new ArrayList<>();
        ArrayList<Double> arr4 = new ArrayList<>();

* To add elements:
        arr.add()  // arr[0] = 1

* To get elements:
        arr.get() // arr[0]

* Length:
        arr.size()  // arr.length

* Print:
        -> System.out.println(arr); // not traversing the array by ourselves

        -> for (int i = 0; i < arr.size(); i++) {
            System.out.print(arr.get(i) + " ");
        }

        -> for (int ele : arr) {
            System.out.print(ele)
        }

* Insertion:
        // 25 21 18 50 10
        arr.add(78)
        // 25 21 18 50 10

        arr.add(1, 100)
        // 25 100 21 18 50 10

        NOTE: Vectors and ArrayList mai add peeche se hota hai!

* Remove:
        arr.remove(idx)

* Reverse:
        Collections.reverse()  // import java.util.Collections

        int i = 0, j = arr.size() - 1;
        while(i < j) {
            int temp = arr.get(i);
            arr.set(i, arr.get(j));
            arr.set(j, temp);
            i++;
            j--;
        }
